CCTV Timestamp Editor

Instructions:
  1. Click "Select Image" and choose your QCCDI.jpg file
  2. The image will load and show the current timestamp
  3. Adjust the timestamp text, position, and font settings as needed
  4. Click "Edit Timestamp" to apply changes
  5. Click "Download Edited Image" to save the result

Note: The default settings are optimized for CCTV timestamps. Adjust position values to match the original timestamp location precisely.
